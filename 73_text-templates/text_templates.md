Java has no built-in text/template; this example implements simple `{{.}}` and `{{.FieldName}}` substitution using string replacement.

___

##### Run Command:
`java text_templates.java`

##### Results:
`Value: some text`
`Value: 5`
`Value: [Go Rust C++ C#]`
`Name: Jane Doe`
`Name: Mickey Mouse`
`yes `
`no `
`Range: Go Rust C++ C# `
